# radfet-current-source-board
Constant-Current Source Board for RADFET (TID dosimeter) for UW Orbital Satellite Design Team. 


Design Specifications: 
28 V source to the board. 10 uA needed for the RADFET board. 5-year mission in LEO. Approx 100 krad of radiation dosage is estimated for the duration of the mission. 

RADFET used is a pMOS transistor, positive holes are charge carriers, needs constant supply of current to track the change in threshold voltage of the transistor over time.
